## Description

**CustomJoinAndQuitMessages** is a Minecraft server plugin that allows you to customize player join and quit messages.

It also provides message customization options with support for special actions, allowing you to create a more personalized server experience.

## Features

- Customizable player join messages.
- Customizable player quit messages.
- Message customization with support for special actions.

## Installation

1. Stop your Minecraft server.
2. Download the latest plugin release from [GitHub Releases][Releases] or [SpigotMC][Spigot].
3. Place the downloaded `.jar` file in your server's `plugins` directory.
4. Start or restart your server.
5. Configure the plugin according to its available configuration options.
